# 2. Valid Anagram (Легкая, 2 балла)
**Ссылка:** [LeetCode: Valid Anagram](https://leetcode.com/problems/valid-anagram/)
## Идея решения
Требуется определить, является ли строка `t` анаграммой строки `s`. 
Основная концепция состоит в том, чтобы считать встречаемость каждого символа. Так как по условию на вход подаются только 26 английских букв нижнего регистра, нам не нужно усложнять логику - достаточно использовать обычный вектор (`std::vector`) ровно на 26 элементов. Это будет работать быстрее хэш-таблицы.

Чтобы правильно привязывать буквы к индексам массива, используем сдвиг по ASCII-коду. Буква 'a' имеет код 97, поэтому индекс считаем по формуле `символ - 'a'`, так как английские буквы нижнего регистра идут с 97-го кода. Таким образом, счетчики хранятся с нулевого по 25-й индекс и не тратят лишнюю память.

Для ускорения алгоритма, "изучение" строк проводим одновременно в одном цикле. Встречаем символ в `s` - увеличиваем его счетчик на 1, встречаем символ в `t` на той же позиции - уменьшаем счетчик на 1. 

## Алгоритм
1. Проверяем длины строк. Если они разные, `t` точно не анаграмма `s`.
2. Итерируемся одновременно по `s` и `t`, сдвигая счетчики вверх и вниз соответственно.
3. Проходим по массиву счетчиков. Если хотя бы один счетчик не равен нулю, значит строки не анаграммы.

## Оценка сложности
* **Время: $O(N)$.** Где N - длина строки. Мы проходим по строкам ровно один раз.
* **Память: $O(1)$.** Нам всегда нужен вектор строго на 26 элементов, независимо от того, сколько весят строки. Дополнительная память константна.

## Ответ на Follow-up в задании
Вопрос: `Что если строки содержат Unicode?`
Если бы строки содержали символы Юникода (около 150 000 графических символов), использовать вектор/массив стало бы неэффективно, так как он получился бы огромным и очень разреженным. 
В таком случае я бы изменил структуру хранения счетчиков на Хэш-таблицу (`std::unordered_map<char, int>`). Ключом был бы сам символ, а значением - счетчик. Логика изменения счетчиков осталась бы прежней, но память выделялась бы только под те символы, которые реально присутствуют в строках. Асимптотика по времени осталась бы линейной O(N).
