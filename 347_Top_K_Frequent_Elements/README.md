# 4. Top K Frequent Elements (Средняя, 6 баллов)

**Ссылка:** [LeetCode: Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/)

## Идея решения
Задача требует найти `k` самых часто встречающихся элементов. Дополнительное условие (Follow-up) просит решить задачу быстрее, чем за O(N log N). Если решать задачу "в лоб" - просто подсчитать частоты в хэш-таблице и отсортировать их, мы получим время $O(N log N)$.

Для получения $O(N)$, хорошо подходит идея корзинной сортировки. 
Суть в том, что максимальная частота любого числа физически не может превышать длину самого массива (это ситуация, когда весь массив состоит из одного и того же числа). Значит, мы можем создать массив "корзин", где **индексом будет частота**, а значением - список чисел с такой частотой.

## Алгоритм
1. **Подсчет частот:** Итерируемся по массиву nums и считаем частоту каждого числа.
2. **Создание корзин:** Создаем массив векторов `buckets` размером `N + 1`. 
3. **Распределение:** Проходим по Хэш-таблице и размещаем каждое число в корзину, индекс которой равен частоте этого числа.
4. **Сбор результата:** Так как самые частые элементы теперь лежат в конце массива `buckets`, просто пробегаемся по нему в обратном порядке. Достаем элементы и складываем в итоговый вектор, пока не наберем ровно `k` штук.

## Оценка сложности
* **Время: $O(N)$.** Подсчет частот занимает $O(N)$. Распределение по корзинам — максимум $O(N)$. Обратный проход по массиву корзин также занимает максимум $O(N)$. Получаем линейное время выполнения.
* **Память: $O(N)$.** Дополнительная память используется под хэш-таблицу и под массив корзин. Размер памяти линейно зависит от входных данных.
