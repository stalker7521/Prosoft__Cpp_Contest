# 5. Binary Search (Легкая, 2 балла)

**Ссылка:** [LeetCode: Binary Search](https://leetcode.com/problems/binary-search/)

## Идея решения
Это  задача на реализацию  алгоритма бинарного поиска. Так как исходный массив уже отсортирован, нам не нужно проверять каждый элемент линейно. 

Cтавим указатели на начало и конец массива, находим середину и сравниваем её с искомым числом (`target`). В зависимости от результата мы можем смело отбросить половину массива и продолжить поиск в оставшейся части.

Важный момент в реализации: середину отрезка я вычисляю формулой `left + (right - left) / 2`, а не `(left + right) / 2`. Это охраняет код от потенциального переполнения типа `int` на очень больших массивах.

## Оценка сложности
* **Время: $O(log N)$.** На каждом шаге мы сокращаем зону поиска ровно в два раза. Для массива из 1 миллиона элементов нам понадобится максимум около 20 проверок.
* **Память: $O(1)$.** Мы используем всего три целочисленные переменные (`left`, `right`, `mid`) для хранения индексов, независимо от размера входного массива.
